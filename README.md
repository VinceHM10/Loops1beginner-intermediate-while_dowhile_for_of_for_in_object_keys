# 🚀 JavaScript Loops Practice

## JSE#3

A JavaScript practice project focused on repeating code and working with iterable data. It covers `for`, `while`, and `do...while` loops; loop control with `break` and `continue`; nested arrays; `for...of` and `for...in`; and iterating over object keys. This project forms part of my study and preparation workflow for the **JavaScript Certified Entry-level (JSE)** certification.

## 📌 Core Learning Objectives

- Use `for`, `while`, and `do...while` loops to repeat instructions.
- Understand when a loop condition is checked.
- Use `break` to exit a loop and `continue` to skip an iteration.
- Iterate through arrays with `for...of`.
- Iterate through object properties with `for...in` and `Object.keys()`.
- Work with nested arrays and access their elements using nested loops.
- Avoid infinite loops by ensuring loop conditions eventually become false.
